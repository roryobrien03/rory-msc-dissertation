# Evaluating polygenic risk scores for endometrial cancer across diverse populations

Code supporting the MSc Statistical Science dissertation validating an endometrial cancer (EC) polygenic risk score (PRS) in the All of Us (AoU) Researcher Workbench (Controlled Tier Dataset v9).

This repository documents the analytical pipeline. 
It is **not independently executable outside All of Us**.
The underlying participant-level genomic and EHR data are controlled-access and cannot leave the Workbench. 
Reproducing the results requires an authorised AoU Researcher Workbench account with CDR v9 access and the specific input files referenced in each notebook. 
What is provided here is the exact analysis code, with outputs cleared, so the methodology is fully inspectable even though it cannot be re-run outside the AoU Workbench.

## Notebooks, in execution order

| Order | Notebook | Produces |
|---|---|---|
| 1 | `EC_Cohort_Definition.ipynb` | Case/control cohort: SNOMED/OMOP-based case ascertainment, WGS/ancestry/sex filters, exclusions (prior hysterectomy, relatedness, QC), self-reported and treatment-identified case additions. Saves the final cohort used by every notebook below. |
| 2 | `EC_Cohort_Characteristics.ipynb` | Baseline characteristics table, the BMI-and-ancestry composition figure, age-reference handling, and incident/prevalent case classification. |
| 3 | `EC_PRS_Extraction.ipynb` | Extracts genotypes (PLINK2, per chromosome), lifts over and harmonises alleles against the supplied EC SNP weights, computes the raw and standardised PRS for the full cohort. |
| 4 | `EC_PRS_Analysis.ipynb` | The main analysis: pooled and ancestry-stratified association models, PRS-only vs. PC-adjusted AUC, apparent-bootstrap vs. cross-validated AUC gain, calibration, functional-form (spline) check, incident-only sensitivity analysis, age/BMI-adjusted models, and all associated figures. |
| 5 | `EC_Menopause_PRS.ipynb` | Secondary/exploratory analysis: an independently derived (SBayesR) menopause-timing PRS, scored and tested against EC case status for comparison with the primary EC PRS. |

`dissertation_plot_style.py` is a shared house-style module (`%run` once per kernel session) used by notebooks 2 and 4 for consistent figure styling and a save-and-upload helper.

## Environment

- All notebooks were run in the All of Us Researcher Workbench (Python 3, standard Jupyter environment), with access to CDR v9 Controlled Tier data.
- Each notebook begins with `%run /home/jupyter/Var_set_2.ipynb`, a Workbench-provided setup script that sets `project_id`, `bucket_output`, `bucket_scripts`, `CDR`/`dataset`, and `DSUB_USER_NAME` from the user's own Workbench environment. 
This file is Workbench-managed and not included here; it is not reproducible outside AoU.
- `EC_PRS_Extraction.ipynb` and `EC_Menopause_PRS.ipynb` submit `dsub` jobs for cloud-based per-chromosome extraction/scoring. 
These cells are kept commented out in this repository and marked "uncomment to rerun from scratch".
They are expensive, environment-specific, and were already run once to produce the score files consumed by later notebooks.
- `EC_Cohort_Definition.ipynb` derives treatment-identified case participant IDs live, by query, each time it runs.
No participant-level identifiers are hard-coded or loaded from an external file, in line with All of Us's policy against sharing participant-level identifiers.
- Python dependencies used across the notebooks: `pandas`, `pandas-gbq`,
  `numpy`, `scikit-learn`, `statsmodels`, `matplotlib`, `seaborn`, `patsy`,
  `scipy`. 
  Platform/cloud tools used by the pipeline (Workbench-managed, not
  pip-installable): PLINK2, GCTB (SBayesR), `pyliftover`, `dsub`, `gsutil`.
  No pinned requirements file is provided, since the notebooks only run inside the Workbench's managed environment.

## Prepared inputs not generated by these notebooks

- **`prs_weights_hg38.csv`** (the EC PRS SNP weights, lifted to GRCh38) —
  `EC_PRS_Extraction.ipynb` loads this file as a prepared input. 
  The supplied file (`ukbb_ec_ecac2018_sbayesr_band.snpRes`, from O'Mara's group) is confirmed to be in GRCh37 (its SNP positions match known GRCh37 coordinates, e.g. rs3131969 at chr1:754182), so a GRCh37→GRCh38 liftover was performed to produce it (99.961% success rate, 1,138,676 / 1,139,118 SNPs lifted). 
  The liftover code (`pyliftover`) is included, commented out, in `EC_PRS_Extraction.ipynb`, since the output file already exists.
  You can uncomment to regenerate it from scratch.
  Neither `prs_weights_hg38.csv` nor the original `ukbb_ec_ecac2018_sbayesr_band.snpRes` is redistributed here (provided for project's purpose, not published as an open-access download)

## Data and disclosure safety

Every notebook in this repository has had all cell outputs and execution counts cleared. 
Each was audited for hard-coded participant-level data, restricted small-cell counts (All of Us prohibits reporting counts below 20), credentials, and identifying file paths, in line with the All of Us data dissemination policy. 
No participant-level data is included anywhere in this repository.
GCS paths that do appear (e.g. the standard `gs://vwb-aou-datasets-controlled/v9/...` genomic data paths) are AoU's own shared, non-identifying dataset locations, not user-specific buckets.

## What this repository is not

This is a documentation and review artefact, not a reproducibility package
in the "clone and run" sense: the controlled-tier data it operates on
cannot be distributed. A reader without Workbench access can follow the
logic end-to-end but cannot execute it.
